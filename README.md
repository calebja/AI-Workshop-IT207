Section 1 — Command Description

This "fancycat" command is a JavaScript implementation of the Linux "cat" command, with a couple changes. The original command displays the full contents of a file to the user.
This new command concatenates three files together, numbers all of the lines throughout all three files, and then displays the full, numbered combination of all three files to the user.
